# Exception Desk — Frontend Demo

A clean, read-only Operations Exception Desk UI built with plain HTML, CSS and vanilla JavaScript.

## Run

Open `index.html` in a browser.

No build step or external dependency is required.

## Included

- Operations overview dashboard
- Exception queue with search/filter UI
- Case detail + evidence panel
- Severity and workflow states
- Source health and import/version UI
- Audit trail
- Role/access indication
- Unknown/missing/stale evidence presentation
- Responsive laptop/mobile layout
- Synthetic demo data only

## Scope note

This is a frontend demonstration. It does not implement a real backend, server-side RBAC, persistent database, real file parsing, or production authentication. Those are backend requirements in the supplied assessment brief and should be implemented separately for a full submission.

## Design basis

The UI uses the terminology and domain rules from the supplied Stock Broking FDE assessment, including settled-vs-pending DP evidence, provenance, unknown states, severity, source versions, and audit history.
